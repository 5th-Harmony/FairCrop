## 📌 Problem Overview
In India's current agricultural supply chain, smallholder and marginal farmers often face severe information asymmetry, fragmented market linkages, and excessive middleman margins. **FairCrop.in** solves these challenges by:
1. Providing **real-time transparent price discovery** across 2,400+ APMC mandis.
2. Eliminating intermediaries through **direct farmer-to-buyer linkages**.
3. Enabling **multi-lingual accessibility** across 22 official Indian languages and voice-enabled search for rural usability.
4. Integrating government welfare schemes (**PM-KISAN, eNAM, PMFBY, AIF**) and agricultural advisories directly at the farmer's fingertips.

---

## 🌟 Key Features

- 🇮🇳 **Government-Aligned Design System:** Built following the design guidelines of digital public infrastructure (India.gov.in, eNAM, Agmarknet) with tricolor branding and glassmorphic aesthetics.
- 🔄 **Interactive Market Linkage Flowchart:** Vector visualization detailing the complete value cycle: **Farm Produce ➔ Fair Price Discovery (₹) ➔ Consumer/Market Linkage**.
- 📈 **Live Mandi Price Ticker:** Dynamic price feed of major commodities (Tomatoes, Onions, Basmati Rice, Wheat, Cotton, Pulses) with modal APMC mandi price breakdowns.
- 🏛️ **Major Agricultural Hubs & Mandis:** Dedicated access to key trading hubs across India (Delhi-NCR Azadpur, Mumbai Vashi, Nashik Lasalgaon, Bengaluru Yeshwantpur, Hyderabad Bowenpally, etc.) with custom landmark vector icons.
- 🗣️ **Multilingual & Voice-Enabled:** Support for 22 scheduled Indian languages with speech-to-text recognition for regional voice searches.
- 🌓 **Adaptive Dark / Light Themes:** Seamless switching between high-contrast dark mode and clean government light mode.
- 📱 **100% Responsive & Accessible:** Fluid design across mobile smartphones, tablets, laptops, and ultra-wide desktops.

## 🚀 Getting Started

### Local Setup
No build tools or server dependencies required — runs in any modern browser:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/FairCrop.git
   cd FairCrop
   ```

2. **Open the project:**
   - Double-click `index.html` to open in your browser, or
   - Use VS Code Live Server: Right-click `index.html` ➔ `Open with Live Server`.
